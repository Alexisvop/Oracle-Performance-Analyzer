# Public-edition acceptance

The laboratory supports deterministic synthetic data, approved SQL/correctness checks, estimated plans, descriptive benchmark statistics, unfavorable results, guarded historical index/statistics experiments and offline report generation. The site preserves EN/ES, keyboard controls, readable tables and responsive charts.

Release acceptance additionally requires: complete reviewed file allowlist and hash manifest; no private credentials/context/history; exact retained numerical observations; satisfied third-party notices; independently installed offline tests/builds; local source/evidence links; and explicit future publication approval. Current outcomes belong to the release checklist, not historical stage summaries.

Group C and Engineering Challenges are not implemented. The initial pre-publication candidate did not create a repository, publish a site, deploy or execute live Oracle tests. The public source repository now exists, and the owner reports a Pages site; hosted revision verification remains blocked by HTTP 403. Those later publication facts do not change the historical tests or authorize new Oracle/Cloudflare operations. [Security](security.md), [development](development.md), [provenance](provenance.md).
