# Public-edition provenance

This edition is a sanitized export of a privately developed engineering project, prepared with owner authorization. Original code/documentation ownership and MIT attribution were confirmed as Alexis Abraham Perez Olvera, 2026. Private conversations, recruiting context, internal prompts, host diagnostics, credentials and Git history are not public inputs.

Unmodified evidence is identified by equal original/final SHA-256 values. Metadata derivatives remove private branch/commit context and unnecessary forensic preflight inventory; retained measurements, sample counts, timestamps, statistics, SQL/results and optimizer observations are unchanged. The scoped forensic fixture manifest has new hashes and is clearly labeled a public derivative. It is not represented as the original full private manifest.

The [public provenance map](evidence/PROVENANCE.json) records original and public hashes and transformation categories. Original bytes remain private and unchanged. This map supports provenance comparison; possession of a hash alone does not independently prove the private original's contents.

Third-party dependencies, Oracle software/output labels and trademarks are not automatically relicensed by the owner's MIT grant. [Notices](../THIRD_PARTY_NOTICES.md), [license](../LICENSE), [security](security.md).

The E04 comparison authorization field is a digest binding the complete compared artifacts, not a permission to gather statistics. Redacting Git metadata changes those bytes, so the public derivative explicitly rebinds only that offline field. Every other comparison value is retained exactly and the source/derivative hashes are recorded.
